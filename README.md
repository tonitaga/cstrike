# INCOMSYSTEM CS 1.6 Server

[`CHANGELOG.md`](./CHANGELOG.md)

## Как подключиться

- В терминале клиента CS 1.6 необходимо написать:
```shell
connect incomsystem-dev-zone.ru
```

## Как запустить?

1) Склонировать к себе репозиторий или скачать в виде архива 

```shell
git clone https://github.com/tonitaga/incomsystem_cstrike.git
```

- [Скачать в виде архива](https://github.com/tonitaga/incomsystem_cstrike/archive/refs/heads/main.zip)


2) В корневой директории находится файл `run_server.bat`

Батник запускает HFS, проверяет доступность страницы кейса, карточек и звука по HTTP, затем запускает TTS и HLDS. При пустом `sv_downloadurl` выбирается локальный IPv4-адрес и порт из `cstrike/hfs/config.yaml`. Временный адрес передаётся серверу через `cstrike/hfs/runtime-fastdl.cfg`.

Если к серверу подключаются из интернета, укажи доступный игрокам адрес в `cstrike/hfs/hfs.cfg`, например `sv_downloadurl "https://fastdl.example.com/cstrike/"`. Явно заданный адрес имеет приоритет перед автоопределением.

Команда `run_server.bat --check` проверяет HFS и ресурсы кейсов без запуска TTS или игрового сервера.

3) Сервер готов к игре!

## Как запустить `Team DeathMatch`?

Для включения режима `Team DeathMatch` выполните следующие действия:

1. Откройте терминал сервера и введите команды:

```
amx_incom_respawn_enable 1
```

- Для отключения режима:

```
amx_incom_respawn_enable 0
```

## Как управлять сервером со стороны клиента?

Администратор может управлять сервером и со стороны клиента, отправляя на него команды. Для этого нужно:

1. Узнать свой STEAM_ID.

* Находясь на сервере, откройте терминал клиента и введите команду status. Она покажет список всех игроков и их STEAM_ID. Скопируйте идентификатор игрока, который будет администратором.

2. Перейдите в файл `cstrike/addons/amxmodx/configs/users.ini`

3. Добавьте в файл строку с правами администратора:

```
"STEAM_1:0:1745810986" "" "abcdefghijklmnopqrstuv" "ce"
```

Чтобы изменения вступили в силу, перезапустите сервер или смените карту:

```
amx_map map_name
```

- Управление происходит командами указанными в файле `users.ini`

Основная команда которая позволяет менять параметры сервера и плагинов это `amx_rcon`

Например:
```
amx_rcon sv_restart 1
amx_rcon map $2000$
amx_rcon amx_incom_respawn_enable 1
```

## Конфигурация дополнительных плагинов

- При неоходимости можно посмотреть все загруженные на сервер плагины при помощи команды

```
amxx plugins
```

В файле `cstrike/addons/amxmodx/configs/plugins.ini` указаны все подключаемые плагины. Ненужные можно отключить, но в основном их можно отключать и программно, не редактируя при этом файл `plugins.ini`

Основные настройки всех плагинов можно увижеть в папке `cstrike/addons/amxmodx/configs/`. Именованные конфигурационные файлы лежат в папках:

- `cstrike/addons/amxmodx/configs/plugins`
- `cstrike/addons/amxmodx/configs/aes`

## Новогодние подарки и снежинки

- `/newyear` открывает меню шести кейсов и коллекцию, `/snowflakes` показывает баланс, `/wintercollection` открывает список полученных скинов.
- Графическая рулетка загружается из `cstrike/motd/newyear/`. По умолчанию используется адрес FastDL из `sv_downloadurl`. Если MOTD размещён отдельно, укажи полный HTTP(S)-адрес `index.html` в `incom_gifts_case_motd_url`. Значение `off` отключает графическую рулетку и оставляет выдачу результата в чате.
- В коллекции выбери полученный скин, чтобы экипировать его. Повторный выбор снимает скин. Выбор сохраняется между подключениями.
- Каждый кейс по умолчанию стоит 60 снежинок. Его пул состоит из четырёх скинов своего оружия (95% суммарно) и четырёх скинов бабочки (5%). Дубликат продаётся автоматически за `3,5 ÷ вероятность конкретного дропа` с округлением вниз. Сумма начисления показывается после остановки рулетки.
- В `cstrike/addons/amxmodx/configs/incom_newyear_gifts.cfg` настраиваются интервал и размер волны, лимит и время жизни подарков, награды за подбор и фраги, цена кейса.
- Для каждой карты точки лежат в `cstrike/addons/amxmodx/configs/incom_gift_points/<карта>.ini`. Админ может встать на нужное место и выполнить в консоли `amx_gift_add`. Команда `amx_gift_remove` удаляет ближайшую точку в радиусе 120 единиц, а `amx_gift_wave` запускает волну для проверки.
- Баланс и полученные скины записываются на сервере по идентификатору игрока. Для начислений и покупки кейсов нужна авторизация.
